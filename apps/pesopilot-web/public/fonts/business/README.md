# Business Mode typography

`plus-jakarta-sans-latin-wght-normal.woff2` is the unmodified Latin, normal-style variable font from `@fontsource-variable/plus-jakarta-sans@5.3.0`, supporting weights 200–800. Only Business Mode selects this font family. It is served from the application origin for offline use; there are no remote font requests or added npm dependencies.
