# Batch 4 dependency security review

2026-11-08, Asia/Manila. Read-only `npm audit --audit-level=high` against the PesoPilot lockfile, plus primary GitHub advisory review. Counts describe affected packages, not a count of independently exploitable vulnerabilities. No exploit was run, no formal compliance claim, no `npm audit fix --force`.

Initial result: **12** packages, **2 critical / 4 high / 6 moderate**, exit 1. Applied only compatible lockfile updates: `happy-dom` **21.0.1 -> 21.0.4**, `follow-redirects` **1.16.0 -> 1.16.2**, `postcss-selector-parser` **6.1.4 -> 6.1.5**. Package manifest ranges were unchanged. Clean install and the full regression suite passed with these patches.

Final result: **9** packages, **2 critical / 2 high / 5 moderate**, **exit 1**. The dependency gate remains failed. npm's proposed remaining remediation entails major upgrades; no such upgrade was introduced without a compatibility review.
